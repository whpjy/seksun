# NX 3D-2D Projection V8

这是用于 NX 12 的 3D 多方向投影与结构化测量 DLL。V8 直接调用 `NxMeasureV27.dll`，并在结构化孔轴特征之上增加工程图尺寸候选生成。

## V8 核心升级

- 支持任意方向圆柱轴，不再假定孔轴为全局 Y 轴。
- 将同轴、相邻的多个圆柱面合并为一个孔、阶梯孔、销或阶梯轴特征。
- 两条外伸腿会作为两个独立外圆柱特征输出，并在适合的侧视图标注长度。
- 每个结构化特征包含稳定 ID、关联 Face Tag、轴线、中心、直径组、总长、置信度、优先级和自动标注开关。
- 同一复合特征只生成一组标注，避免每个圆柱面分别标注造成重复。
- 孔距只自动输出同排或同列的最近邻，抑制全组合孔距带来的交叉引线。
- 相同直径且重复分布的孔自动合并为 `n×Ø...`，不再逐孔重复标注。
- 自动输出孔阵列横向、纵向中心跨度 `X/Y`。
- 正视轴向视图只标孔类特征；销、腿和外圆柱改在侧视图标注长度。
- 从投影后的真实圆弧边拟合半径，并将相同半径合并为 `n×R...`。
- 对位于视图平面内的斜直边输出真实长度与角度候选。
- 显示值最多保留 3 位小数；JSON 中仍保留几何计算精度。
- 黑色标注直接写入每张 `view_xxx.svg`，不只出现在 `index.html`。
- 标注采用白底黑字、矩形碰撞检测、多行文字和自动引线。
- 同时输出无标注版本 `view_xxx_plain.svg`。

## 测量输出

`NxMeasureV27.dll` 当前产生以下结构化结果：

- `AxialFeatures`：圆孔、阶梯孔、外圆柱、阶梯外圆柱及同轴复合特征。
- `Slots`：任意轴向的腰形孔候选。
- `RadiusCandidates`：相同圆角半径的分组候选。
- `ThicknessCandidates`：基于平行平面证据的板厚候选。
- `Confidence/Priority/AutoAnnotate`：控制哪些结果可直接进入图面，哪些仅保留给后续确认或 2D 匹配。

V7 当前自动上图的内容以高置信度 A/B 级轴向特征为主。圆角和板厚候选先写入 `nxmeasure_v27.json`，后续应结合 2D 标注语义、视图可见性和剖切结果再决定是否上图，避免把工艺圆角全部铺到视图中。

## 编译

先编译测量核心：

```powershell
cd ..\NxMeasureV8
.\build_v27.ps1
```

再编译投影 DLL：

```powershell
cd "..\3d-2d Projection"
.\build.ps1
```

输出文件：

```text
bin\Nx3d2dProjectionV8.dll
bin\NxMeasureV27.dll
bin\NxMeasureV26.dll
```

`NxMeasureV26.dll` 暂时随包保留，用于兼容旧版代码和历史报告；V8 主流程只调用 V27 结构化 API。

## 在 NX 中运行

1. 在 NX 12 中打开 `.stp`、`.step` 或 `.prt`。
2. 选择“文件 → 执行 → NX Open”。
3. 选择 `bin\Nx3d2dProjectionV8.dll`。
4. 等待 NX 列表窗口显示导出完成和结果目录。
5. 打开结果目录中的 `index.html` 查看全部候选视图。

不要只复制 V8 主 DLL；至少应将 `Nx3d2dProjectionV8.dll`、`NxMeasureV27.dll` 与兼容依赖 `NxMeasureV26.dll` 放在同一目录。

## 输出结构

```text
模型名_3d2d_projection_yyyyMMdd_HHmmss\
├── manifest.json
├── measurements.json
├── nxmeasure_v27.json
├── index.html
├── view_001.json
├── view_001.svg
├── view_001_plain.svg
└── ...
```

测量值来自 NX 三维 B-Rep 几何和模型单位，不是从 SVG 像素反算。每条投影线保留 Body Tag、Edge Tag 或 Face Tag，可供后续 2D-PDF 匹配结果回到 NX 中定位。

## 当前边界与下一阶段

- 当前仍输出较完整的 B-Rep 线框，尚未进行正式工程图级隐藏线消除。
- `manifest.json` 已包含每个视图的中心剖切候选平面，但 V8 尚未按 PDF 中的 A-A、C-C 等剖切线生成精确剖面。
- 腰形孔采用保守策略：候选会输出到 JSON，只有达到自动标注门槛时才上图。
- 圆角、板厚、沉孔深度、螺纹和 GD&T 仍需结合 2D 图纸语义建立“要求值—3D 实测值”比对层。
- 达到 97% 以上核对准确率不能只依赖自动投影；需要用带人工复核结论的样本集分别统计尺寸召回率、错误匹配率和要求项覆盖率。
