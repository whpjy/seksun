# 第一步：验证 NX Open C# 程序

## 编译

在 PowerShell 中进入本目录，执行：

```powershell
.\build.ps1
```

生成文件：

```text
bin\NxHello.dll
```

## 在 NX 12 中运行

1. 先打开任意一个 `.prt` 零件。
2. 在 NX 中选择“文件 → 执行 → NX Open”。
3. 选择生成的 `NxHello.dll`。
4. NX 的“列表窗口”应显示：

```text
NX 自动测量工具：连接成功。
当前零件：……
第一步测试已通过。
```

部分 NX 12 界面的命令也可能位于“菜单 → 文件 → 执行 → NX Open”。
